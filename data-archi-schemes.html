🔥 Décision Ingestion

Le choix entre streaming et batch dépend des exigences de latence, du pattern de lecture et des cas d'usage (IoT, ETL). Si aucune condition streaming n'est remplie, le batch est sélectionné par défaut.

💾 Décision Stockage

Le Data Lake est toujours activé. Le Warehouse, NoSQL et Search Engine sont ajoutés conditionnellement selon le type de données, les patterns de lecture et les cas d'usage spécifiques.

⚙️ Décision Processing

Le choix entre traitement distribué et serverless dépend du volume de données et du pattern analytique. La plateforme ML est ajoutée si le cas d'usage le nécessite.

📊 Décision Serving

La couche de serving détermine comment les données sont exposées aux utilisateurs finaux : outils BI pour le reporting, APIs pour les applications temps réel.

🛡️ Recommandations Transverses

En plus des couches principales, l'outil recommande des composants transverses : orchestration (toujours), sécurité (selon le niveau requis) et monitoring (toujours).

💰 Estimation des Coûts

Les coûts sont estimés à partir du budget mensuel et du volume de données. La répartition type : stockage (~$23/TB), compute (40%), réseau (15%), licences (20%).
